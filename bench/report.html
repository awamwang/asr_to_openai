五、结论

  1. 代理自身开销（前置 + 后置 + 路由）几乎可以忽略：输入已是 16kHz 单声道 WAV 时走免 ffmpeg 快路径，前置/后置均为毫秒级， 端到端耗时 ≈ 上游 API 耗时。
  2. 模型速度差距主要来自上游：最快与最慢相差 39.7 倍 （tencent/16k_zh 346ms vs siliconflow/SenseVoiceSmall 13.77s）。
  3. 音频越长绝对耗时越高，但多数模型 RTF 远低于 1，说明处理快于实时。
  4. 以下模型本次全部调用失败：baidu/80001，需检查密钥/网络。
